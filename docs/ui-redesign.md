# HireFlow UI / UX 改造

本次为本地界面改造，不更新生产环境。保留现有 API、模型 Prompt、数据类型、Repository、统计口径和业务校验；没有新增依赖。

## 审查结论与设计规范

原界面存在装饰横幅和宣传内容占用首屏、字号偏小、辅助文字对比度偏低、各模块重复卡片、候选人反馈表单遮挡资料等问题。

统一采用浅灰页面、白色内容区、近黑正文和蓝色主操作：

| 项目 | 规范 |
| --- | --- |
| 页面 / 内容背景 | `#F5F5F7` / `#FFFFFF` |
| 正文 / 次级文字 | `#1D1D1F` / `#6E6E73` |
| 主操作 / 分隔线 | `#0071E3` / `#E5E5E7` |
| 字体 | 系统无衬线字体，正文 14px，表格 13px，标题 24–28px |
| 间距 | 4px 基准；常用 8 / 12 / 16 / 24 / 32px |
| 圆角 | 控件 8px，内容面板 12px，大工作区 14–16px |
| 动效 | 180–220ms；支持 prefers-reduced-motion |
| 表面 | 轻边框，弱阴影；内部分组优先使用留白与分隔线 |

Ant Design 组件主题集中在 `src/components/design-theme.ts`。页面级 CSS tokens、布局和响应式规则集中在 `app/globals.css`；三个模块样式文件同步统一中性色。

## 页面调整

- 全局：简化品牌区、导航与顶部操作；当前路由增加 aria-current，提供跳过导航链接；本地存储及重置放到内容底部。
- 看板：移除装饰横幅；指标形成统一横排，突出待安排面试入口；图表改为单色层级，保持动态统计和原有口径。
- 岗位：统一筛选与表格，增加岗位名称列宽；表单保留原字段分组，长表单在弹窗内滚动，底部操作保留可见空间。
- 候选人：统一表格，显示面试 / 推荐状态和申请更新时间；详情抽屉加宽，资料、匹配、反馈及历史分开组织。
- 简历初筛：保留四步流程；去除嵌套卡片，上传、岗位与沟通信息按章节组织；增加明确的读取 / 分析状态反馈。
- 招聘流程：中性阶段底色、轻量卡片；保留横向看板和列表、反馈折叠入口及区块间距。
- 助手：减少消息边框，弱化会话侧栏，统一输入框、快捷问题、引用和统计卡片。
- 面试反馈：统一时间、自然语言输入、建议状态、确认与最近记录的视觉；候选人详情中的手动录入移至「录入反馈」Tab，保存逻辑不变。
