# UI 可读性与状态视觉优化

本次只调整 CSS、Ant Design Theme 和展示组件，不改招聘数据、Repository、AI / RAG、硬条件预筛、统计及状态流转规则。没有新增依赖，没有推送或部署。

## 实际问题与调整

- 清理全局与模块样式中的 8–11px 小字号，包括小屏覆盖规则。页面标题 24px / 600，区域标题 17px / 600，姓名与岗位名称 15px / 600，表格正文 14px，说明 13px，次级信息及标签至少 12px，统计数字 30–32px。
- 主文字 #1D1D1F，正文 #30343B，次要文字 #667085，弱化文字 #7A8190；主要业务信息使用正文或次要文字层级。
- 表头加深、增加字重；搜索筛选控件保持 38px；候选人列表明确列宽，通过表格内横向滚动保留文字可读性。
- 原 StatusTag 的包含式正则将「未通过」错误匹配为绿色，现改用统一 StatusBadge 精确映射，StatusTag 保留兼容导出。
- 当前首页已移除装饰 Banner。本次压缩现有业务待办条，放大指标、漏斗、图表轴标签与招聘动态，未新增横幅。
- Kanban 列改为 #F8F9FB，白色卡片，列宽至少 264px，列标题 15px、姓名 15px、岗位 14px、学历经验 13px；保留横向滚动。去掉卡片底部分隔线，强化 Hover、键盘焦点与选中状态，不降低淘汰卡片整体透明度。

## 状态语义

| 语义 | 颜色 | 示例 |
| --- | --- | --- |
| 进行中 | 蓝 | 招聘中、已安排 |
| 待处理 | 琥珀 | 待处理、待安排、待业务复筛 |
| 已通过 / 已完成 | 绿 | 已通过、通过、已完成 |
| 未通过 | 红 | 未通过、已淘汰 |
| 已结束 / 暂停 | 中性灰 | 已结束、已暂停 |
| 待确认 | 紫 | 待确认、待定、待 HR 审核 |
| 流程位置 | 中性描边 | HR 初筛、一面、二面、HR 面、Offer |

每个标签保留完整文案与可访问名称；阶段使用竖形标记，与结果状态的圆点区分。未知状态保守使用中性灰。不同页面使用同一套映射，不根据文字包含关系推断结果。

## 验收

TypeScript、ESLint、57 项既有自动化测试和生产构建通过。

在 1440px 和 1280px 下实际检查招聘看板、岗位列表、候选人列表、流程 Kanban、流程列表和候选人详情抽屉。验证卡片可点击、抽屉可关闭、看板 / 列表可切换；页面没有整体横向溢出，表格和 Kanban 的横向滚动保留在各自容器内。

浏览器采样实测：正文对比度 12.50:1、姓名 16.83:1、次要信息 4.97:1、各语义状态约 6.13–7.30:1。所有被采样的业务文字与状态均达到 AA 4.5:1；这不是对全站每个像素的完整无障碍认证。

运行本地生产服务（默认端口 3112）后可用 `node scripts/readability-browser.cjs` 复验；可通过 READABILITY_TEST_URL 指定地址。验收不调用业务 API 或模型。截图及结构化测量结果保存在 `.local/readability`，不会提交到 Git。
